# FreeStack Target Board & Device Profiles

This directory contains target-specific hardware definitions, kernel configurations, firmware requirements, and rootfs assembly profiles.

## Supported Targets
- **`x200-libreboot`**: ThinkPad X200 with Libreboot / Coreboot payload (100% free software, zero binary blobs).
- **`reform-imx8mq`**: MNT Reform open-hardware laptop with NXP i.MX8MQ processor.
