# Sovereign Fuzzing Harnesses

This directory houses the root integration fuzzing suites, corpus, crash dumps, and execution harnesses for LibreDroid and FreeStack.

## Usage
- Run quick batch: `make quick` or `./run.sh quick`
- Run soak triage: `make all` or `./run.sh`
- Artifacts and triage reports are output to `freestack/dist/fuzz-reports/`.
